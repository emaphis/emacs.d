# FSharp yasnippets.

Here is a set of F# yasnippets useful for bbatsov's fsharp-ts-mode.

Fsharp-ts-mode <https://github.com/bbatsov/fsharp-ts-mode>

Inspired by a set of Caml/Ocaml snippets found here: <https://github.com/pymander/yasnippet-caml-mode>

I surprisingly I couldn't find any yasnippets for F#, I found some Ocaml snipptets.

The Ocaml snippets worked suprisingly well given that Ocaml is similar enough to F#, but there was too much of an impedanance mismatch.

Installation: Create the directory ~/.emacs.d/snippets/fsharp-ts-mode/ and copy the snippets.

Run M-x yas-reload-all.

Snippets Written by Grok, inspired by Pymander
